# Error Registry

- Human-readable: [REGISTRY.md](REGISTRY.md)
- Machine-readable: [registry.json](registry.json) (also shipped as `errors.json` in the interface package)

Generated by `python3 scripts/devx/gen_error_registry.py` from `contracts/price-oracle/src/errors.rs`
(meaning = doc comment) and [remediation.json](remediation.json) (class, cause, remediation).

CI (`--check`) fails when:
- a code has no remediation entry (or an entry is stale);
- the generated files are out of date;
- a published code is removed, renumbered, or its number reused ([errors.lock.json](errors.lock.json) is append-only).

Classes: `config` (fix deployment/admin config), `caller` (fix the request), `transient` (retry later), `state` (contract state makes the call inapplicable).
