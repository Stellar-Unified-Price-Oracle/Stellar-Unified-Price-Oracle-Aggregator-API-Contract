# Endpoint × Authority Matrix

Every public entrypoint of `PriceOracleContract` (`contracts/price-oracle/src/lib.rs`) with the authority it requires. `rbac_escalation_tests::matrix_covers_every_endpoint` fails when an endpoint is added to or removed from `lib.rs` without updating this table, so the matrix cannot silently drift from the source tree (#467).

Authority values:

| Value | Meaning |
|---|---|
| `admin` | Current admin must `require_auth` (primary admin; delegated roles do not apply unless listed). |
| `role:<R>` | `rbac::check_role` for role `R`; the primary admin implicitly holds every role. |
| `caller:<arg>` | The named argument must `require_auth` (source, consumer, relayer, voter, …); the callee then checks that the address is registered for the action. |
| `signature` | No Soroban auth; an Ed25519 signature from a registered key is verified instead (see `signed-submission-binding.md`). |
| `consumer` | Consumer access control (`consumer_auth::check_consumer_authorized`). |
| `public-read` | Read-only query; no state is written that grants authority. |
| `contract-self` | Callable only with `current_contract_address` as the configured oracle (cross-contract self call). |
| `public` | Permissionless by design (e.g. `initialize` guarded by `AlreadyInitialized`, keeper/crank functions, idempotent maintenance). Reviewed in #467: none of these write configuration, roles, or prices without a downstream check. |

Totals: 494 endpoints — admin: 183, caller: 49, contract-self: 1, public: 10, public-read: 247, signature: 4
